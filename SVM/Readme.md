# Problem Statement:

You are working as a machine learning engineer for a medical research organization.

Researchers have measured different physical characteristics of cell nuclei from biopsy samples. They want a model that can classify a tumor as:

Benign
Malignant

Your task is to build an SVM classification model that predicts the diagnosis from the measured cell characteristics.

---

## Solution:

- Build a **Support Vector Machine Model** by 'Scikit-Learn' and from 'Scratch'
- also did **Exploratory Data Analysis** and **Feature Engineering**.

Result:

| **Method** | **Accuracy** | **Precision** | **Recall** | **F1 Score** |
|---|---|---|---|---|
| Scikit-Learn | 99.59% | 100% | 99.21% | 99.60% |
| SVM - From Scratch | 97.13% | 100% | 94.44% | 97.14 |
